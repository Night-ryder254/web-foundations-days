About QuickNotes

QuickNotes is a simple note-taking app designed to help you capture ideas quickly and easily.

How to Use QuickNotes

  1. Type your note in the input field.
  2. Click the "Add Note" button to save it.
  3. Your notes will be displayed in the list below.

Features

  • Add new notes
  • View your existing notes
  • Simple and user-friendly interface

Keyboard Shortcuts

Shortcut Action
Ctrl + N Focus on the note input field
Ctrl + Enter Add the note to the list
